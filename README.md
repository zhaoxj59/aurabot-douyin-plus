# Aurabot QQ 抖音增强版

基于 Aurabot 社区模块 `douyin` v2.3.6（MIT）增强。基础能力（专用 Edge 浏览器、扫码登录、定时刷、点赞评论、验证码熔断）沿用原版；新增的在下面。

## 增强版新增（对照需求文档 V1.2）

| 需求 | 落地 |
|---|---|
| 分享白名单（抖音里的人，可选） | `lib/people.mjs`：分享 / @ / 黑名单三类名单，存 `douyin-plus-people.json`，重启不丢；面板勾选，QQ 里也能加 |
| 黑名单优先级最高 | 同一人在白名单和黑名单里时，分享和 @ 一律拒绝 |
| 评论区 @ 白名单 | 模型想 @ 时，@ 白名单里的人（评论里真·@，对方收得到通知），不是假 @ |
| 每日额度（方案 §4） | `lib/quotas.mjs`：浏览 100、点赞 30、评论 10、分享 10、@ 5、汇报 3，活动时段 09:00–22:00；存在 `douyin-plus-quotas.json`，可改，不写死 |
| 内容分类（方案 §2） | `lib/classify.mjs`：科技/AI/数码/历史/知识优先；购物、广告、直播带货直接跳过（不消耗互动额度）；非商业测评保留，带购物信号的测评跳过 |
| QQ 主动汇报 | 每天 12 / 18 / 21 点有活动就发日报到主人 QQ（看了多少、分享了什么、还剩多少额度），一天最多 3 次 |
| QQ 自然语言控制（方案 §6） | `lib/commands.mjs`：开始刷抖音 / 暂停 / 恢复 / 今天只看科技 / 今天不要评论 / 暂停点赞 / 分享精选 / 查看今天的情况 / 查看剩余额度 / 今天不要看购物内容 |
| 熔断 | 沿用原版：验证码、操作频繁、账号异常 → 当天停手，QQ 通知主人，截图发主人 |

## 本期不做的（方案 §10）

自动购物、下单、领券、加购物车、自动群发、向陌生人主动发消息、绕过验证码、自动发片、ComfyUI。

## 安装

1. 先备份：跑 `install.ps1`，它会自动备份现有的 Aurabot 配置和抖音模块数据，失败回滚。
2. 把本目录整个拷到 Aurabot 的社区模块目录（或按 Aurabot 面板「模块市场」本地安装流程装）。
3. 在 Aurabot 面板里开「刷抖音增强版」，先扫码登录抖音，再在白名单里加人。
4. 卸载：跑 `uninstall.ps1`，恢复备份。

## 注意

- 增强版和原版 `douyin` 模块不要同时开，两个都会定时刷，会打架。原版已卸载的直接装增强版。
- 分享只在抖音里发（抖音私信，视频卡片），不走 QQ；日报和熔断通知走 QQ 发给主人。
- 额度放宽（评论 10、分享 10）比原版保守值宽松，新号前 3 天额度减半的保护还在；跑几天没被风控再放宽。
